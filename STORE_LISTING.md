# Chrome Web Store listing

## Name

Chat Dinger – Notification Sound for ChatGPT

## Summary

Get a sound alert when ChatGPT finishes responding. Switch tabs and Chat Dinger will tell you when your answer is ready.

## Detailed description

Stop watching ChatGPT think.

Chat Dinger plays a sound when a ChatGPT response or image is ready. Switch tabs, keep working, and return when you hear the ding.

Features:

- Choose from ten notification sounds.
- Get an optional Chrome notification when a result is ready.
- Control alerts from the extension popup.
- See your total wait time, total dings, and milestones.
- Save a snapshot of your metrics.
- Keep your prompts and responses private.
- Get automatic repair attempts when ChatGPT controls change.

Chat Dinger does not read or send your chat text. It keeps your settings and statistics in Chrome local storage.

Chat Dinger gets a small selector file from `chatdinger.com`. This file helps it stay compatible with ChatGPT interface changes.
Optional error reports help the developer find detection failures. Reports contain error codes and version data, with no chat text.
Error reports are off by default.
